# Voice2Campaign

一款面向品牌营销场景的轻量化消费者洞察工具：上传 CSV/TXT 用户评论后，自动归纳情绪、主题、使用场景、核心痛点与产品卖点，并生成可直接使用的社交媒体文案和短视频脚本。

## 在线体验

GitHub Pages：`https://doudou404.github.io/voice2campaign/`

## 核心功能

- 上传或粘贴消费者评论
- 生成情绪分布与高频主题
- 提炼使用场景、用户痛点和产品卖点
- 生成社媒文案与短视频脚本
- 一键复制或导出分析结果
- 示例数据可直接体验，分析在浏览器本地完成

## 本地运行

```bash
npm install
npm run dev
```

生成 GitHub Pages 静态文件：

```bash
npm run build:pages
```

产物位于 `docs/`。

## 项目定位

这是一个 AI 营销解决方案作品 Demo，展示从用户声音采集、洞察提炼到营销内容输出的完整轻量化工作流。
